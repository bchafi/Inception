**APT** and **APK** are both software package managers used in different Linux operating systems (or mobile platforms), but they belong to completely separate ecosystems.

- **APT (Advanced Package Tool):**
  - Used by Debian, Ubuntu, and related Linux systems.
  - Manages .deb software files.
  - Requires separate commands to update lists and install software (apt update then apt install)
- **APK (Alpine Package Keeper):**
  - Alpine Linux and lightweight Docker containers.
  - Manages .apk software files.
  - Automatically updates repository indexes when running install commands.

# VOULT / KEY / ACCESS for docker / GPG:

these three commands securely prepare your Debian system to trust and verify the official Docker software before you download it.

_sudo install -m 0755 -d /etc/apt/keyrings_

> This command creates a secure folder (/etc/apt/keyrings)

- install: Instead of using mkdir (to make a directory) and chmod (to change permissions) separately, the install utility does both safely in a single step.
- -m 0755: Sets the strict permissions (mode) for the new directory. The 0755 means the owner (root) can read, write, and execute, while everyone else on the system can only read and execute.
- -d /etc/apt/keyrings: The -d flag instructs the system to create a directory at this specific path.

_sudo curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc_

- curl: A standard command-line tool used to download files from the internet.
- -fsSL: These are execution flags that tell curl exactly how to behave. It instructs it to fail silently on server errors (f), run in silent mode without showing a progress bar (s), show an error message if it fails (S), and automatically follow any URL redirects (L).
- https://.../gpg: The exact web address targeting Docker's official public key.
- -o /etc/apt/keyrings/docker.asc: The -o (output) flag tells curl not to print the downloaded text onto your terminal screen, but instead to save it directly into a file named docker.asc inside the secure directory you just created.

_sudo chmod a+r /etc/apt/keyrings/docker.asc_

- a+r: This is the permission argument. The a stands for "all" (meaning the owner, the group, and all other users on the system). The +r stands for "add read permission." Together, it explicitly grants read access to everyone.

# the actual map to find the software:

*echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/debian  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null*

- echo "deb ... stable": This constructs the specific configuration string required by Debian.

- arch=$(dpkg --print-architecture): This dynamically figures out what kind of CPU your Virtual Machine is running (like amd64 or arm64) so it downloads the right version.

- signed-by=/etc/apt/keyrings/docker.asc: This explicitly links the repository to the GPG key you downloaded in the previous steps, ensuring apt verifies the signature before installing anything.

- $(. /etc/os-release && echo "$VERSION_CODENAME"): This automatically checks your operating system version and inserts your specific Debian codename (like bookworm or bullseye).

- | (The Pipe): This takes the text generated by the echo command and passes it forward as input to the next command.

- sudo tee /etc/apt/sources.list.d/docker.list: Because standard output redirection (>) doesn't work with sudo, we use the tee utility. It takes the piped text and writes it directly into a new file named docker.list inside the protected apt configuration directory.

- "> /dev/null": The tee command normally prints what it writes to the terminal screen. This part acts as a black hole, swallowing that output so your terminal stays clean.

# What is YAML?

YAML is a computer data serialization language.

A YAML document represents a computer program's native data structure in a human readable text form. A node in a YAML document can have three basic data types: 

- Scalar
  Atomic data types like strings, numbers, booleans and null
- Sequence
  A list of nodes
- Mapping
  A map of nodes to nodes. Also known as Hashes, Hash Maps, Dictionaries or Objects.
  Unlike in many programming languages, a key can be more than just a string.
  It can be a sequence or mapping itself.

On top of that, YAML allows to serialize all other data types and classes:
- Alias and Anchor
  For serializing References / Pointers, including circular references.
- Tag
  With Tags it's possible to define custom types/classes.
